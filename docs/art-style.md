# Durian 线上桌游美术风格

> 核心方向：**像素水果 + 可爱但有性格的角色卡 + 轻量桌游 UI + 爽快翻牌/出牌反馈 + 清新欢乐的派对氛围**
>
> 读者对象：美术设计师 / UI 设计师 / AI 美术生成模型。

整体美术风格希望呈现一种**清新、明快、轻松、有趣的线上派对桌游感**。视觉上以**精致的像素风水果、具有个性的角色卡牌、简洁现代的桌游 UI**为核心，同时加入少量富有表现力的动画、粒子和动作特效，让整个游戏既有传统实体桌游的温度，又具备数字游戏的即时反馈与爽快感。

## 1. 整体视觉基调

整体采用**清新派对风 + 精致像素风 + 轻量化数字桌游**的结合。

画面不追求复杂、厚重或写实，而是强调**干净、明亮、活泼和有辨识度**。背景与 UI 保持简洁，为水果、卡牌和玩家操作留出足够的视觉空间。

色彩以**清新的绿色、黄色、橙色、浅蓝色以及柔和的暖色**为主，不使用过度饱和、刺眼的霓虹色。不同水果可以拥有鲜明而独立的代表色，使玩家能够快速识别牌面。

整体应该有一种：

**“阳光、夏日、朋友聚会、轻松玩一局桌游”**

的感觉。

---

## 2. 水果美术

水果是游戏最重要的视觉元素之一。

水果采用**高质量像素风（Pixel Art）**表现，但不是传统游戏中粗糙的大颗粒像素，而是更加精致、细腻的现代 Pixel Art。

水果应该具有：

* 清晰的轮廓
* 简单但有层次的明暗
* 少量高光与阴影
* 可爱的比例
* 明显的水果辨识度
* 适度夸张的表情或动作

例如苹果、香蕉、西瓜、葡萄、草莓、榴莲等，都可以进行一定程度的拟人化设计，但不要完全变成卡通人物。

水果本身应该仍然保持“水果”的感觉，同时拥有一点点**可爱、调皮甚至欠揍的性格**。

尤其是榴莲，可以作为整个游戏的视觉记忆点，拥有非常强的辨识度。

---

## 3. 大猩猩角色

大猩猩是游戏中非常重要的角色形象。

整体设计不希望采用恐怖、写实或者过于强壮的路线，而是偏向**可爱、笨拙、搞怪、具有喜剧感的大猩猩**。

大猩猩可以拥有非常丰富的动作和表情，例如：

* 得意地拍胸口
* 惊讶地瞪大眼睛
* 抱着水果
* 抢牌
* 偷偷观察其他玩家
* 生气
* 狂喜
* 一脸无语
* 被榴莲砸到
* 抽到好牌时疯狂庆祝

角色卡可以通过不同的姿势、表情和小道具体现个性。

大猩猩整体造型可以与水果保持统一的 Pixel Art 语言，使角色、卡牌和水果看起来属于同一个世界。

---

## 4. 卡牌设计

卡牌应该具有明显的**实体桌游卡牌感**。

卡牌整体结构简洁，不堆叠过多文字和装饰。

重点突出：

**卡牌图案 → 卡牌类型 → 核心信息**

卡面可以使用圆角卡片、柔和阴影、轻微纸张或塑料质感，让它具有“拿在手里的实体卡牌”感觉。

不同卡牌类型可以拥有不同的主色和视觉符号，但整体设计语言保持统一。

例如：

* 水果牌：突出水果 Pixel Art
* 大猩猩牌：突出角色动作
* 特殊行动牌：突出动作图标和动态元素
* 特殊事件牌：加入更明显的视觉效果

卡牌不应该过度复杂，而是做到**一眼就能理解，一眼就能记住**。

---

## 5. 翻牌动画

线上版本需要特别强调**“翻牌”的仪式感**。

翻牌不应该只是简单地让一张图片突然出现，而应该模拟实体桌游中“把牌翻过来”的感觉。

例如：

**卡牌轻微抬起 → 横向翻转 → 卡面出现 → 轻微弹性回弹**

整个过程非常短，但要有明显的重量感。

可以加入：

* 轻微的卡牌阴影变化
* 卡牌翻转时的 motion blur
* 很轻的粒子
* 柔和的光效
* 卡牌落下时的小幅弹跳

让玩家产生一种：

**“啪——翻开了！”**

的即时反馈。

---

## 6. 放牌与出牌动画

出牌动作应该保持**简洁、快速、有反馈感**。

玩家把牌拖到桌面中央时，卡牌可以：

**拖动 → 松手 → 快速落下 → 小幅弹起 → 定位**

卡牌落下时产生非常轻微的：

* 阴影
* 尘埃粒子
* 小星星
* 圆形扩散波纹

但不要做成夸张的技能特效。

核心感觉应该是：

**轻、脆、快、爽。**

让玩家每一次出牌都能感觉到“我做了一个动作”。

---

## 7. 动作特效与粒子

特效整体遵循**“少而精”**的原则。

不追求 MMORPG 式的大量光效，而是使用非常轻量的 2D 动效和 Pixel Particle。

例如：

**抽到好牌：**
小星星、闪光、轻微弹跳。

**抢到水果：**
水果快速飞向玩家头像，留下短暂轨迹。

**特殊卡触发：**
卡牌中央出现短暂的图标、圆形波纹或者像素爆炸。

**榴莲出现：**
可以拥有一个稍微更有记忆点的特殊动画，例如榴莲快速滚入画面、轻微震动，然后停下来。

**玩家失败 / 被攻击：**
头像轻微晃动、卡牌震动、少量碎片飞出。

特效持续时间应该很短，避免影响游戏节奏。

---

## 8. UI 风格

UI 应该体现**现代线上桌游**的感觉。

尽量减少复杂的 HUD 和传统电子游戏式按钮。

采用：

* 圆角
* 简洁图标
* 柔和阴影
* 半透明面板
* 清晰的层级
* 少量像素装饰

按钮不需要非常复杂，强调“像实体桌游组件一样简单”。

例如：

**开始游戏 / 出牌 / 结束回合 / 查看手牌 / 聊天**

都可以设计成非常直观的按钮。

整体 UI 应该让玩家觉得：

**“我不是在玩一个复杂的电子游戏，而是在电脑上和朋友一起玩一桌很有趣的桌游。”**

---

## 9. 桌面场景

游戏桌面可以采用简洁的**桌游桌 / 野餐桌 / 夏日聚会**视觉。

背景不需要大量细节。

可以使用：

* 浅色桌面
* 柔和纹理
* 少量水果装饰
* 小型植物
* 阳光
* 轻微纸张或木质纹理

让画面拥有一定空间感，但绝对不要抢夺卡牌和水果的视觉中心。

---

## 10. 动画整体原则

所有动画都应该遵循：

**短、快、轻、有弹性。**

可以大量使用：

* Ease Out
* Ease In-Out
* Squash & Stretch
* 微小弹跳
* 位移
* 旋转
* 缩放

避免大量复杂的 3D 动画。

尤其是卡牌和水果，应该有一种略微“Q弹”的感觉，让整个游戏更加轻松和有生命力。

---

## 11. 最终风格关键词

**Pixel Art / Cute / Fresh / Party Game / Digital Board Game / Fruit / Gorilla / Card Game / Playful / Clean UI / Soft Colors / Light Effects / Snappy Animation / Minimal Particle / Summer / Casual / Social / Cozy**

最终希望玩家看到游戏画面时产生一种非常直观的感觉：

**“这是一款看起来很清爽、很可爱、很容易上手，而且和朋友一起玩一定很欢乐的线上派对桌游。”**
