# 机器人席位与决策协议

机器人是服务端内部席位，不创建或伪造 Colyseus `Client`。大厅只有房主可以发送：

- `add_bot`：加入唯一一个机器人席位 `__bot__`。
- `remove_bot`：移除机器人席位。

机器人作为 `PlayerState` 计入开局人数、起始玩家选择和顺时针轮转；它没有网络连接，也不会出现在 `Room.clients`。机器人库存始终保存在服务端用于真实结算，但机器人策略不得读取 `__bot__` 库存。

## 公开信息策略

机器人决策只汇总其他玩家和双人局公共库存的公开水果库存。水果订单比较左右需求：优先选择需求不超过公开总库存的一边；两边都满足时取左边；两边都不满足时选择超出较少的一边。

抽到猩猩牌后逐张检查尚未翻转的公开订单。只有翻转能降低当前公开库存计算出的爆单风险时才翻转，否则直接继续抽牌。

机器人轮到自己时：有订单且当前公开计算已经爆单立即摇铃；未爆单时订单达到 2 张摇铃；没有订单继续抽牌。机器人动作使用房间现有 `clock` 调度，返回大厅或解散时由现有 clock 清理机制取消后续动作。

## 房主解散

房主发送既有 `end_game` 后，服务端立即锁定房间，广播 `room_closed`，并在短延迟后断开所有连接。页面收到该事件后返回首页；该流程与机器人席位无关。
