# 小局云朵发话协议

小局云朵发话使用独立的 Colyseus 消息通道，不进入普通聊天记录，也不使用聊天限流器。

## 客户端入站

- `round_phrase`：发送 `{ phraseId }`。仅 `resolving` 阶段有效，每位玩家每小局最多一次；特殊短句仅当前库存为猩猩牌的玩家可用。
- `request_round_phrases`：请求服务端补发当前小局已经产生的全部云朵事件。客户端完成监听注册后应发送一次，用于覆盖重连补发早于监听注册的情况。

## 服务端出站

`round_phrase` payload：

```ts
{
  playerId: string;
  round: number;
  phraseId: string;
  text: string;
  sentAt: number;
  eventId: string;
}
```

## 当前短句目录

菜单根据本轮结算身份和库存牌类型自动筛选，每组显示四条：

- **赢家 · 普通牌**：有点意思、你就说赢没赢吧、给压压、不吃压力
- **赢家 · 猩猩牌**：猜到了老弟、有点意思、你就说赢没赢吧、Wooooo~（猩猩专属叫声）
- **输家 · 普通牌**：失算了、完了吃压力了、有坏币、给你运完了
- **输家 · 猩猩牌**：居然是这个、失算了、完了吃压力了、有坏币

后续调整短句时，必须同步更新客户端 `roundPhraseTypes.ts`、服务端 `roundPhrasePolicy.ts` 和本目录；服务端仍以自身 ID/文案为权威，拒绝不符合当前结算身份的短句。

服务端拥有短句 ID 与文案，忽略客户端自定义文本。`eventId` 用于客户端去重，`sentAt` 用于恢复约 5 秒的剩余可见生命周期。新一轮开始或返回大厅时清空缓存；玩家重连和显式请求时仅补发当前 `resolving` 小局缓存。
